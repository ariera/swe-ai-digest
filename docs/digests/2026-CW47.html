External sandboxes for coding agents (2026-11-17)

Simon Willison introduces the "external sandbox" pattern for coding agents, where agent-executed code runs inside an isolated sandbox (via WebAssembly, Apple Containers, or QEMU) while the agent itself remains outside it. Three open-source server implementations are released, compatible with Claude Code, Codex, and Pi. The pattern mitigates prompt injection risks and limits network access, making it safer to experiment with local models on personal machines.
