Quoting Felix Rieseberg (2026-10-05)

Felix Rieseberg of Anthropic describes an architectural shift in Claude's Cowork product: moving from local VM-based model inference to fully cloud-hosted inference and sandboxed VMs per session, with the desktop app handling only device-level file access.
