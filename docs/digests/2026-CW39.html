Jev introduces a new shape of LLM - System One, aka Decision Models (2026-09-21)

Simon Willison reviews Jev, a new "decision model" from TypeSafe AI that takes unstructured text input and returns typed probabilistic outputs (yes/no, choice, or score) rather than text — positioning it as a fast, cheap alternative to LLMs for classification tasks like spam detection, ranking, and labeling.
