Don't classify. Hallucinate! (2026-08-14)

Simon Willison highlights a prompting technique by Doug Turnbull: instead of asking an LLM to classify against a large existing tag vocabulary, let the model freely "hallucinate" fitting tags, then use vector embeddings to map those generated tags to the closest real ones.
